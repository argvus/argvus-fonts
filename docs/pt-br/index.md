# ARGVUS Fonts

O ARGVUS inclui uma seleção cuidadosa de fontes otimizadas para legibilidade e consistência visual em todo o desktop. O sistema de tipografia é projetado para funcionar perfeitamente com a interface ARGVUS.

## Fontes Incluídas

O pacote ARGVUS Fonts inclui:
- **Inter** - Sans-serif moderno para elementos de UI
- **Fira Code** - Fonte monospace para terminal e editores de código
- **Noto Sans** - Sans-serif rico em Unicode para texto internacional
- Fontes do sistema adicionais para compatibilidade

## Instalação

As fontes são instaladas como parte do ARGVUS ou separadamente:

```bash
pacman -S argvus-fonts
```

## Configuração

Configure fontes através de:
- ARGVUS Control Center → Fonts
- Preferências de aplicativos individuais
- Arquivos de configuração GTK/Qt

## Especificações de Fonte

- **Fonte de UI**: Inter 10pt
- **Fonte de Terminal**: Fira Code 10pt
- **Fonte do Sistema**: Noto Sans 11pt

Para configurações de fonte personalizadas, edite seus arquivos de configuração relevantes (`.config/gtk-3.0/settings.ini`, etc.)
