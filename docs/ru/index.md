# Шрифты ARGVUS

`argvus-fonts` устанавливает входящие в комплект семейства шрифтов в папку `/usr/share/fonts/`. Он сам шрифт не выбирает: выбор хранится в конфигурации ARGVUS и применяется к каждой поверхности компонентом, который её использует.

## Установленные семейства

| Семейство | Файлы | Используется для |
| --- | --- | --- |
| IBM Plex Mono | Обычный, Курсив, веса от Thin до Bold | Семейство по умолчанию для рабочего стола и моноширинных целей |
| Bitstream Vera Sans Mono | Моноширинный шрифт | Доступно как моноширинное семейство |
| Terminess Nerd Font | Моно, Процентное и обычное начертание с Nerd-глифами | Доступно как моноширинное или пропорциональное семейство |
| Symbols Nerd Font | Иконки-глифы | Доступно как иконографическое семейство |
| Font Awesome 7 Free | Brands, Regular и Solid | Доступно как иконографическое семейство |

Каждое семейство шрифтов включает лицензию (`LICENSE.txt` или `OFL.txt`) рядом с файлами шрифтов.

## Где выбирается шрифт

Предпочтения шрифтов являются каноническими настройками в `config.json`:

- `fonts.targets.<target>` содержит семейство, стиль и размер каждого элемента интерфейса (панель задач, телеметрия, Панель управления, система, приложения, терминал и браузер).
- `fonts.rendering` содержит параметры сглаживания, подсказок, порядок субпикселей и DPI.

Изменяйте их в Центре управления (Внешний вид > Шрифты). Размеры не фиксированы этим пакетом: значение, отображаемое в Центре управления, является действующим. Не редактируйте сгенерированные файлы в `data/generated/`; они перезаписываются из `config.json`.

## Многоязычная подстраховка

Пакет требует `noto-fonts-cjk`, предоставляющий китайские, японские и корейские глифы, наряду с `noto-fonts` и `noto-fonts-emoji`. Fontconfig выбирает запасные глифы для активного языка; выбранные пользователем основные семейства остаются в силе. Терминальные приложения требуют терминала с поддержкой Unicode и запасными шрифтами. Проверьте с `fc-match "monospace:lang=ja:charset=65e5"` или `fc-match "monospace:lang=ko:charset=d55c"`. Шрифты обеспечивают отображение, а не метод ввода.
